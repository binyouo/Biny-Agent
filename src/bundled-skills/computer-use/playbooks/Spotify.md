# Spotify

Bundle id: `com.spotify.client`。桌面版是 **Electron**，无障碍树需要"叫醒"。

## 第一拍通常是薄的

Electron 应用默认不暴露无障碍树。第一次观察可能只拿到很少的元素——
**再观察一次**通常就完整了（观察时会显式打开它的无障碍开关）。

## 布局

- **左侧栏**：主页 / 搜索 / 你的音乐库（下面是歌单）
- **顶部**：搜索框、账号
- **主区**：卡片网格 + 列表
- **底部**：播放条（当前曲目、播放控制、进度条、音量）

## 常用做法

| 动作 | 做法 |
|---|---|
| 播放 | 双击卡片或列表行 |
| 播放/暂停 | 点底部按钮，或空格（需先建立焦点） |
| 搜索 | 顶部搜索框；Electron 的输入框一般接受合成键盘输入 |

## 注意

- 播放点击后的状态可能不会立即更新；先查看动作后的画面，必要时重新观察，确认之前不要重复点击。
- 搜索框需要先有焦点，再按 `Return`；否则可能切换播放状态。搜索或切换页面后短暂显示「没有结果」时，可重新观察，等待网络结果后再决定下一步。
- 返回链接时优先使用界面提供的 `open.spotify.com` 原始链接，不把 `xpui.app.spotify.com` 的内部地址当作分享链接；保留链接中的资源类型，不把专辑 ID 改成歌曲 ID。
- **右键菜单**用 `perform_secondary_action`（AX 菜单明确不受支持时才尝试合成右键）。
  直接点右键在部分版本上不弹出菜单。
- 滚动会消费当前观察，继续操作前使用新观察中的引用。

# Spotify

Bundle id: `com.spotify.client`。桌面版是 **Electron**，无障碍树需要"叫醒"。

## 第一拍通常是薄的

Electron 应用默认不暴露无障碍树。第一次观察可能只拿到很少的元素——
**再观察一次**通常就完整了（观察时会显式打开它的无障碍开关）。

## 布局

- **左侧栏**：主页 / 搜索 / 你的音乐库（下面是歌单）
- **顶部**：搜索框、账号
- **主区**：卡片网格 + 列表
- **底部**：播放条（当前曲目、播放控制、进度条、音量）

## 常用做法

| 动作 | 做法 |
|---|---|
| 播放 | 双击卡片或列表行 |
| 播放/暂停 | 点底部按钮，或空格（需先建立焦点） |
| 搜索 | 顶部搜索框；Electron 的输入框一般接受合成键盘输入 |

## 注意

- **右键菜单**用 `perform_secondary_action`（AX 优先，失败退化成合成右键）。
  直接点右键在部分版本上不弹出菜单。
- 界面滚动时 `ref` 会失效，滚完要重新观察。

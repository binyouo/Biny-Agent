# Apple Music

Bundle id: `com.apple.Music`。**无障碍树完整**，优先用元素 ref，别一上来就点像素。

## 布局

- **左侧栏**：现在就听 / 浏览 / 广播 / 资料库（下面还有 歌曲、专辑、艺人、歌单）
- **顶部**：搜索框 + 后退/前进
- **主区**：卡片网格（专辑、歌单、推荐）
- **底部**：播放条（当前曲目、播放/暂停、上一首/下一首、音量）

## 常用做法

| 动作 | 做法 |
|---|---|
| 播放推荐内容 | 左侧栏点「现在就听」，再到主区双击一张卡片 |
| 播放某张专辑/歌单 | 双击卡片（单击只选中） |
| 播放/暂停 | 先点一次曲目建立焦点，再按空格 |
| 搜索 | 点击侧栏「搜索」，再对搜索框使用 `set_value`；搜索会自动提交，结果未出现时重新观察 |

## 注意

- 主区是**滚动列表**：目标不在可视区时先滚动，再观察一次拿到新的 ref。
- `filterField` 只过滤当前视图，不搜索整个资料库或 Apple Music 目录。找歌单时可选择「你的资料库」搜索，或向下滚动侧栏；找不到搜索入口时先将侧栏滚到顶部。
- 侧栏进入子视图后，可用 `backBtn` 返回上一层。
- 将曲目加入播放队列：点曲目的 `More`，再选择 `Play Next` 或 `Play Last`；没有 `More` 时可对曲目使用 `perform_secondary_action` 打开菜单。
- 播放条在视图底部，**不受主区滚动影响**，是判断"在不在播"的可靠位置。
- 卡片双击才会播放；单击只是选中，别把单击当成"点了没反应"。

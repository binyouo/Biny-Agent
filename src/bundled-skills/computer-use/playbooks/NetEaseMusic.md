# 网易云音乐

Bundle id: `com.netease.163music`（随版本可能变，用列表工具确认）。

## 为什么需要单独一份

网易云是 Qt 应用，**不暴露可用的无障碍树**。观察它时 `elements` 是空的，
但截图和窗口框照常返回——**截图是你唯一的视觉锚点**，所有点击都从截图读坐标。

## 已知的硬坑

**搜索框不接受合成键盘输入。** 点击有效，`type_text` 会返回成功但文字进不去
（Qt 自绘控件丢弃合成键盘事件）。实测对比过：同一个搜索框，用两套独立的
实现都失败——是应用自身限制，不是驱动问题。

所以：**别指望在搜索框里打字**。要放某首歌/某个歌单，走左侧导航或双击列表项。

## 布局

- **左侧栏**：推荐 / 精选 / 播客 / 漫游 / 关注 / 我的
- 「我的」下面：我喜欢的音乐、最近播放、我的播客、创建的歌单
- **顶部**：搜索框（放大镜图标 + 占位提示词，占位词会变，不要当成输入内容）
- **主区**：歌单卡片、每日推荐、推荐歌单

## 能做什么

| 动作 | 做法 |
|---|---|
| 播放某个歌单 | 在左侧栏双击它（单击只选中，双击才进） |
| 播放单曲 | 双击列表里的那一行 |
| 播放/暂停 | 点底部的播放按钮，或空格键（需先点过列表建立焦点） |
| 切歌 | 底部上一首/下一首按钮 |

## 每次动作后回读

网易云的界面变化很直接（主区内容整块换掉），**动作后的回执截图基本就够判断了**。
但"是否真的开始播放"要看底部播放条的状态，别只看主区变了就算成功。

## 坐标会漂

窗口尺寸、主题、版本都会让位置变。**每次都从当前截图重新读坐标**，
不要沿用上一轮的数值。

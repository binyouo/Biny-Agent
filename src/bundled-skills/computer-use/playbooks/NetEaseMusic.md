# 网易云音乐

Bundle id 通常为 `com.netease.163music`，以当前应用列表为准。选定准确的 PID 和窗口，不复用旧进程号。

## 搜索指定歌曲

1. `ComputerList` 选择应用和窗口，再 `ComputerObserve`。某些版本只有根窗口或没有可用 AX 控件；截图仍是有效的视觉依据，不需要一直切换 `interactiveOnly` 寻找不存在的搜索框引用。
2. 从当前截图定位顶部搜索框，以当前 `capture_id` 点击。检查动作后截图是否显示搜索框聚焦；不要猜坐标或使用旧帧。
3. 搜索框已确认聚焦且输入方式可用时，用 `ComputerSequence` 合并 `type_text` 和 `press_key`（`key: "Return"`），检查最后返回的结果截图。自绘搜索框可用 `inputMethod: "unicode"`，不传 `elementToken`。中文不要强制用只支持当前键盘布局字符的 `physical`。首次尝试或此前输入无效时，先单独输入并检查回执与截图，再决定是否提交。
4. 核对结果页中的歌曲名与歌手；同名或不同版本无法确定时询问用户。只要求搜索时，到这里结束。只有用户要求播放时，才用当前结果截图双击匹配的歌曲行（`clickCount: 2`），并核对底部播放条、播放状态及可得进度；只选中行不算已开始播放。

动作已经返回截图时直接使用，不为获取同一画面再观察。确需刷新自绘页面时可用 `content: "image"`；没有可读控件文字时，不使用等待文字出现的条件。一次检查仍无法确认输入或结果时，说明具体阻碍，不反复观察空控件树。

## 输入与许可边界

后台键盘事件可能被自绘控件丢弃。`keystrokes_may_be_dropped` 或 `unverified` 不是成功，也不证明完全没有副作用：先检查返回截图，必要时重新观察，不能盲目重放。

观察返回 `foregroundAllowed: true` 时，可明确选择 `delivery: "foreground"` 点击搜索框、输入、按 Return；每一步仍使用新观察凭据。前台路径会激活准确目标窗口；窗口身份或聚焦状态无法确认时停止输入。未开启许可时，请用户在“设置 → Computer Use”开启“允许明确批准的前台动作”，不自行改设置、不静默升级。

没有 AX 搜索框时，不使用 `set_value` 或 `select_text` 编造引用。只有现成列表确实含目标歌曲时，才可直接双击播放；不能用其他歌曲或歌单代替用户指定的内容。

## 坐标与监督

窗口大小、主题和版本会改变布局，每次从当前截图重新定位。监督预览不是观察凭据，关闭或遮住它不等于停止任务；暂停、人工接管或停止使用对应控制按钮。

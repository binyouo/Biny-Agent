# 网易云音乐

Bundle id: `com.netease.163music`（随版本可能变，用列表工具确认）。

## 为什么需要单独一份

网易云**不暴露可用的无障碍树**。观察它时 `elements` 是空的，
但截图和窗口框照常返回——**截图是你唯一的视觉锚点**，所有点击都从截图读坐标。

（进程列表显示它内嵌 CEF/Chromium，外面还有一层原生壳；总之对外表现为无 AX 树。）

## 已知的硬坑：搜索框收不到键盘输入

点击有效，但**键盘输入进不去**——`type_text` 会返回成功，文字却不在框里。

实测过三种路径，都不行：

| 路径 | 结果 |
|---|---|
| Unicode CGEvent（默认） | ❌ 没进去 |
| 物理键码（按键盘布局翻译字符） | ❌ 没进去 |
| 把应用调到前台再输 | 未验证成功 |

**判别方法**：输入后看搜索框里的占位词有没有消失。占位词还在 = **焦点压根没进去**，
不是输入被丢——这说明问题在「键盘焦点」而不是「输入法」。

所以：**别在这类自绘输入框上打字**。要放某首歌/某个歌单，走左侧导航，
或直接双击列表项。需要"精确到某一首"时，先请用户手动搜一次。

## 布局

- **左侧栏**：推荐 / 精选 / 播客 / 漫游 / 关注 / 我的
- 「我的」下面：我喜欢的音乐、最近播放、我的播客、创建的歌单
- **顶部**：搜索框（放大镜图标 + 占位提示词，占位词会变，不要当成输入内容）
- **主区**：歌单卡片、每日推荐、推荐歌单

## 能做什么

| 动作 | 做法 |
|---|---|
| 播放某个歌单 | 在左侧栏双击它（单击只选中，双击才进） |
| 播放单曲 | 双击列表里的那一行 |
| 播放/暂停 | 点底部的播放按钮，或空格键（需先点过列表建立焦点） |
| 切歌 | 底部上一首/下一首按钮 |

## 每次动作后回读

网易云的界面变化很直接（主区内容整块换掉），**动作后的回执截图基本就够判断了**。
但"是否真的开始播放"要看底部播放条的状态，别只看主区变了就算成功。

## 坐标会漂

窗口尺寸、主题、版本都会让位置变。**每次都从当前截图重新读坐标**，
不要沿用上一轮的数值。

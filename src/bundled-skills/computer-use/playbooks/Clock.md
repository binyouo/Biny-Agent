# 时钟

Bundle id: `com.apple.clock`。无障碍树可用。

## 世界时钟

1. 点工具栏的「世界时钟」标签页，从各时钟容器读取已有城市；地图下方的位置列表可能在删除后没有及时更新。
2. 如果目标城市不在列表中，点「添加时钟」，在弹窗的搜索框用 `set_value` 输入城市，再点城市结果。

## 计时器

1. 点工具栏的「计时器」标签页。
2. 先从开始/停止按钮判断当前状态；如果计时器正在运行或暂停，询问用户是否取消已有计时器。
3. 将时长换算成时、分、秒；时钟无法设置超过 23:59:59 的单个计时器。
4. 找到标识为 `TimePicker` 的容器——它有三个滑块子元素：时、分、秒。
5. 对**每一个**滑块：先点击聚焦，再**输入两位数字**。
   - ⚠️ **不要用 `set_value`**：这个控件要求真实按键，直写值不生效。
   - 最多两位；小时 ≤ 23，分秒 ≤ 59。
6. 点「开始」按钮。

## 秒表

1. 点工具栏「秒表」标签页。
2. 从开始/停止按钮的文字读状态：
   - 显示「停止」= 秒表**在跑** → 问用户要不要停或重来
   - 显示「开始」= 秒表**停了** → 点它启动

## 闹钟

1. 点工具栏「闹钟」标签页。
2. 点「添加闹钟」按钮。
3. 在弹出的表单里：
   - 日期时间区用 `set_value`，格式**照抄它当前的值**；AM/PM 单选不用管，改时间会自动跟着变。
   - 重复日：七个 S M T W T F S 开关，逐个点。
   - 其余：标签、铃声、稍后提醒开关。
4. 点「存储」。

## 注意

「时钟」的控件偏原生，`set_value` 对多数元素有效——**但计时器滑块是例外**，
必须用按键。遇到 `set_value` 没反应，先怀疑是这类控件。

# 时钟

Bundle id: `com.apple.Clock`（桌面版，随系统版本可能不同）。无障碍树可用。

## 计时器

1. 点工具栏的「计时器」标签页。
2. 找到标识为 `TimePicker` 的容器——它有三个滑块子元素：时、分、秒。
3. 对**每一个**滑块：先点击聚焦，再**输入两位数字**。
   - ⚠️ **不要用 `set_value`**：这个控件要求真实按键，直写值不生效。
   - 最多两位；小时 ≤ 23，分秒 ≤ 59。
4. 点「开始」按钮。

## 秒表

1. 点工具栏「秒表」标签页。
2. 从开始/停止按钮的文字读状态：
   - 显示「停止」= 秒表**在跑** → 问用户要不要停或重来
   - 显示「开始」= 秒表**停了** → 点它启动

## 闹钟

1. 点工具栏「闹钟」标签页。
2. 点「添加闹钟」按钮。
3. 在弹出的表单里：
   - 日期时间区用 `set_value`，格式**照抄它当前的值**；AM/PM 单选不用管，改时间会自动跟着变。
   - 重复日：七个 S M T W T F S 开关，逐个点。
   - 其余：标签、铃声、稍后提醒开关。
4. 点「存储」。

## 注意

「时钟」的控件偏原生，`set_value` 对多数元素有效——**但计时器滑块是例外**，
必须用按键。遇到 `set_value` 没反应，先怀疑是这类控件。

# Notion

Bundle id: `notion.id`。**Electron**，和 Spotify 一样第一拍的无障碍树偏薄，**观察两次**。

## 编辑器的特殊性

Notion 是块编辑器，光标位置和选区比普通文本框复杂：

- 点块内任意位置会把光标放到**块的边缘**，不一定是你要的位置。
- 要精确定位，先点进块，再用 `select_text` 的位置和长度设置 UTF-16 选区，或按方向键移动。
- 按文字选区时，内置 `ComputerAction` 使用 `matchText`；外部 MCP 的 `select_text` 使用 `text` 查找，均不会修改正文。内置 `ComputerAction` 的 `text` 则会替换当前选区；外部 MCP 选区后要替换内容，按工具要求取得新观察，再使用 `type_text`。
- 普通文本块中，`Return` 新建块，`shift+Return` 在块内换行。列表项末尾按 `Return` 会延续列表；在空列表项按 `Return` 结束列表。
- 代码块中，`Return` 在块内换行，`shift+Return` 退出代码块。
- 引用块中，`Return` 退出引用块，`shift+Return` 在块内换行。

## 选区和占位文字

- `cmd+a` 的范围取决于当前状态：空块中光标有焦点时会全选文档的所有块；非空块中先选中该块内容；整块已选中时再按一次会选中所有块。替换之前先确认选区，避免覆盖其他块。
- 空块中的 `New page`、`List`、`To-do`、`Write, …` 等是占位文字，直接输入即可替换，不必先选中或删除。
- 新页面的标题通常为空；点标题内部文字元素输入标题，按 `Return` 后开始编辑正文。选中已有块后，按 `Return` 进入该块内容编辑。
- 正文有焦点时，可按 `cmd+a` 两次，再按 `Up` 或 `Down`，最后按 `Return` 编辑首块或末块；也可先选中所有块再点击目标块。使用 `cmd+f` 查找文字，按 `Escape` 关闭查找后可定位到匹配文字。

## 常用做法

| 动作 | 做法 |
|---|---|
| 在页面末尾追加 | 点最后一个块下方空白，直接输入 |
| 插入新块 | 在块末尾回车，再输入 |
| 改标题 | 点击标题内部文字并确认焦点，替换前核对选区；空标题直接输入 |
| 切换页面 | 左侧栏点页名；页面嵌在列表里，目标不在可视区要先滚动 |

## 注意

- 输入后**回读确认**：Notion 有输入法/自动补全干扰，`type_text` 成功不等于内容对。
- 出现斜杠菜单（输入 `/`）会挡住后续输入，按 Escape 关掉再继续。
- Markdown 语法会被即时转换（`# ` 变标题、`- ` 变列表），要写原文得先转义。
- 输入 `>` 可创建折叠清单，输入 `|` 可创建引用块；以当前界面的转换结果为准。

# 隐私脱敏

Biny 支持在对话模型请求离开本机之前，将规则匹配到的敏感数据自动替换为安全占位符；当收到大模型回复或工具调用时，在本地自动将占位符还原为真实原值，确保本地工具正常执行。该功能默认关闭。

## 工作机制

```
[用户输入 / 本地上下文]
        ↓
  1. 敏感数据识别与替换（本地保留映射表，敏感值替换为占位符）
        ↓
  2. 发送出站请求至模型服务商（模型仅看到占位符）
        ↓
  3. 模型返回文本或工具调用参数
        ↓
  4. 本地精准还原（根据请求映射快照，将占位符还原为真实值）
        ↓
[本地执行工具（如浏览器用原密码登录）/ 渲染展示]
```

### 规则识别范围与上下文保护

- **敏感类型覆盖**：支持识别常见 API Key、私钥、显式密码字段、邮箱地址、手机号码、部分身份证件、银行账号及设备标识符，并辅以校验和过滤。
- **上下文感知与排除**：
  * **手机号与账号**：结合字段名、相邻标签与字符边界综合判定。电话字段与国家区号正常脱敏；明确的订单号、用户 ID、工单号等业务流水号予以保留；嵌在较长字母数字组合中的数字片段不单独替换。
  * **密码识别**：文字中以 `=`、`:` 或 `：` 赋值的 `password`、`passwd`、`DB_PASSWORD` 等字段，按密码字面量识别；引号内包含的空格与转义字符作为完整密码处理；系统环境变量引用、类型声明及已遮蔽占位符不作重复替换。
  * **边界说明**：规则不保证穷尽所有自然语言表达，未命中规则不代表绝对不存在敏感数据。

## 开启与配置

- **Desktop 桌面端**：在「设置 → 隐私脱敏」中开启并保存。
- **命令行配置**：
  ```bash
  biny config set redaction.enabled true
  ```
- 配置项保存在全局 `redaction.enabled` 中。CLI 修改后，已运行的客户端需重新加载配置以应用更改。

## 多轮对话与回复还原

- **会话级映射隔离**：每次请求会捕获当前会话的全部有效映射快照。即使历史轮次经过上下文压缩，只要当前进程内存中仍保留映射，模型在后续轮次返回旧占位符依然能被准确还原。不同会话的映射相互隔离。
- **流式与结构化还原**：
  * **流式回复**：流式传输时，按 choice、工具调用与内容块分别拼接跨分块的占位符碎片，拼齐后执行原子替换。
  * **容错匹配**：兼容模型返回时占位符的大小写漂移、括号内空格或单边括号缺失，但必须匹配合法的哈希值。
- **出站系统提示说明**：出站请求若包含占位符，Biny 会在请求中附加说明，指导模型在回复或工具参数中原样保留占位符，由本机负责还原，不要猜测原值。

## 缓存连续性与目标隔离

- **Prompt Cache 保护**：在同一发送目标（Provider 端点与协议）下，已处理过的历史文本与字段会复用既有脱敏决定，后续轮次识别出的新值不追溯改写旧历史，最大程度保护服务商的上下文缓存前缀（Prompt Cache）。
- **目标切换**：切换到不同模型服务商或端点后，历史内容按当前已知敏感词重新脱敏；切回原目标时继续复用原决定。

## 存储、重启与密钥管理

- **哈希密钥（redact.key）**：占位符哈希密钥存储于全局配置目录的 `redact.key`（权限严格限定为当前操作系统用户独占读写）。并发 Runtime 共享同一份密钥。
- **重启边界**：系统重启后，原值映射表随内存释放清空（**原值绝不落盘**）；但凭借相同的 `redact.key`，若后续再次输入相同原文，可重新生成相同的稳定占位符。若没有原文，仅凭历史占位符无法在重启后还原密码。

## 查看脱敏审计记录

在 Desktop「设置 → 隐私脱敏」中可直观审查脱敏流转：
- **双栏对照审计**：点击单条请求可查看模型、服务商、替换次数、独立占位符数，并支持双栏对比「原始输入」与「厂商接收到的样子」。
- **数据完全驻留本地**：审计详情仅在请求进程的本地内存中暂存（受约 8 MB 内存预算约束，超出按 FIFO 淘汰最早记录），不向硬盘落盘明文日志。
- **会话映射容量**：单进程最多缓存 128 个近期会话的映射，每会话最多 5 万个值，超出时按 LRU 策略淘汰最久未访问条目。

## 处理范围与边界说明

- **生效范围**：仅作用于内置对话模型链路的文本字段（用户消息、系统提示、工具参数与返回值）。
- **不受脱敏影响的边界**：
  * 协议元数据（协议 ID、模型名、工具名、签名推理数据、HTTP 认证头）保持原样。
  * 二进制文件、图片内容、独立生图与视频分析、远程 Embedding、MCP 自带的私有网络请求及 ACP 外部 Agent 的流量不经过此脱敏管线。
  * 脱敏不会改写或清理已存在于本地 SQLite 或 JSONL 中的历史会话记录。

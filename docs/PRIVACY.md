# 隐私脱敏

Biny 在内置对话模型请求离开本机前，将规则识别的敏感文字替换为占位符；收到回复后，在本机还原已知占位符，让工具使用原值执行。功能默认关闭。

## 工作方式

1. 你发出请求，Biny 检查即将发送的文字，识别敏感值。
2. 本机保留原值与占位符的对应关系，将识别出的值替换后发送给模型供应商。
3. 模型回复文字或工具调用时，Biny 根据本次请求的映射快照还原占位符。
4. 工具收到还原后的参数，再在本机执行。例如浏览器登录使用原密码，供应商请求中的已识别密码使用占位符。

开启后，Biny 在对话模型的 HTTP 请求边界处理文字：用户消息、系统文字、工具结果、工具参数与辅助模型调用中被规则识别的值会换成占位符；本机会话和工具仍使用原值。规则覆盖常见密钥、私钥、显式密码字段、邮箱、手机号及部分证件、银行账号和设备标识，并对部分格式进行校验。规则不理解所有自由文本，可能漏报或误报，不应把“没有命中”理解为没有敏感信息。

## 开启与配置

在 Desktop「设置 → 隐私脱敏」开启并保存，或执行 `biny config set redaction.enabled true`。开关默认关闭，写入全局配置的 `redaction.enabled`；Desktop 通过设置事务保存并更新空闲 Runtime，忙碌时遵循共享设置的保存门禁。CLI 修改配置后，已运行的客户端需要重新加载配置。

## 多轮对话与回复还原

每次请求捕获所属会话仍保留的全部映射，以及本次实际替换的值。回复可还原早先回合的占位符，即使压缩后的当前请求未再次携带原值；之后的请求或容量淘汰不改变已捕获的映射。其他会话的值不会参与还原。没有会话身份的辅助调用仍使用独立映射，不跨调用复用。回复兼容占位符大小写变化、括号内空格、缺少一个或全部括号，但必须匹配已知的完整类型与哈希；未知、哈希被改写或嵌在更长标识中的内容保持原样。JSON 字符串按层转义，流式回复按 choice、工具调用和内容块分别拼接跨事件占位符。

## 上下文压缩与缓存

已识别且至少四字符的值在新文字中再次出现时复用替换。每次请求先发现敏感值再替换，避免同一请求里新文字较早出现的原值漏遮。已经处理过的相同文字与字段语义复用原先替换位置，后来识别的值不追溯改写旧历史，减少脱敏造成的缓存前缀变化；压缩生成的新摘要重新处理。该记录有界且只驻留内存，重启或淘汰后按当时已知值重新处理；上下文压缩、模型切换等本身造成的缓存变化仍然存在。

上下文压缩不会取消脱敏：新摘要仍需替换，模型返回的占位符仍需还原。旧值能否还原取决于当前进程是否仍保留映射，不能仅凭摘要里有占位符判断原值仍然可用。

## 存储与重启

同一会话中，同类原值的占位符稳定。占位符哈希密钥保存在全局配置目录的 `redact.key`（默认 `~/.config/biny/redact.key`，设置 `BINY_AGENT_DIR` 时随该目录迁移），新建文件使用仅当前用户可读写的权限；并发 Runtime 共用完整发布的同一份密钥。重启后读取同一密钥与会话身份，可以从重新提供的原文生成相同占位符；原值映射不落盘，因此仅有旧占位符时不能在重启后恢复密码。密钥损坏或无法读写时请求报错，不覆盖旧文件或改用随机密钥继续发送。

## 查看脱敏记录

「隐私脱敏」页查看当前项目 Host 中驻留会话的最近请求，可按最近 7/30 天、日期、供应商、会话和类型组合筛选，列表每页显示 20 条。日期图、汇总与流线图基于当前保留的记录，不代表完整历史。流线图展示会话到本机再到供应商的路径；点击节点可筛选。可读请求即使没有命中任何敏感内容，也会保留观测记录，计数为 0，列表标记“未替换”，详情显示“本次未替换，原样发送”并默认展开完整正文。

列表只读取摘要，点击请求后按需读取详情；详情顶部展示请求模型、供应商、会话、请求字节数、独立占位符数与替换次数。内容默认双栏对照，可切换原文与“厂商看到的样子”。记录按整个 JSON 请求体展开，包含角色、模型、参数和未修改字段；不包含 HTTP 认证头。高亮值支持悬停、点击或键盘聚焦查看原值和占位符，详情可切换上一条、下一条请求；连续未改动字段默认收起，可展开逐项查看路径与内容；长改动段默认显示首次命中附近的上下文，可展开全部已保留内容。

回合结束自动刷新，也可手动刷新；短时间重进设置复用摘要。读取失败保留已有摘要并提示错误。

## 记录保留与资源上限

计数表示发送前的替换次数，重复出现在历史中的值会重复计数，不等于独立敏感值数量，也不证明厂商接收成功。

详情包含本机原文，仅驻留请求进程内存，不写入新增日志。不按固定条数截断；按摘要和详情的序列化文本长度估算，进程共用约 8 MB 预算，超出后淘汰最早记录（不是 JavaScript 堆内存硬限制）；单条以约 100 万序列化字符、2000 个字段为保留预算，优先保留命中字段并保持原请求顺序；超出时明确标记整条及被截断字段，不把部分内容标为完整请求。清除记录只清除观测详情，不破坏正在使用的回复还原映射；退出请求进程后清空。

会话映射最多保留 128 个最近使用的会话，每个会话最多 5 万个值、800 万字符，达到上限淘汰最久未使用的会话或值，不再要求重启 Runtime；已发出请求的还原快照独立保留。单次请求自身所需映射超限时仍拒绝发送。

每会话最多记住 65,536 段已处理文本及 20 万个替换位置，仅保存文本指纹与位置，不额外保存原文副本。

请求／非流式响应最多缓存 1600 万字符，SSE 待处理事件最多 200 万字符；超限或请求 JSON 解析失败会报错，不将未处理正文发送给厂商。

## 处理范围与限制

脱敏只作用于内置对话模型链路的文字字段。协议 ID、模型名、工具名、签名或加密内容、编码附件和工具定义结构保持不变，工具定义的 description 可脱敏；工具参数中的同名字段属于用户数据，仍按内容处理。签名推理内容保持原样，不能承诺其中的敏感值被替换。认证头不改写。图片及附件二进制、独立图片生成和视频分析入口、远程 embedding、MCP 自带网络调用、外部子代理及 ACP 的网络流量不经过这条链路。本功能不改变这些入口的授权，也不清洗已有本地会话或日志。

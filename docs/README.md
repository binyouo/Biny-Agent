## 阅读约定

命令示例中的 `<session-id>`、`<browser-id>` 等表示需要替换的参数，不要连尖括号一起执行。示例以已构建并链接的 `biny` 为入口；源码开发时可在仓库中使用 `pnpm dev --` 替代命令开头的 `biny`。

文档描述当前实现与使用方式。模型服务是否可用取决于配置、账户与网络；系统权限和界面操作需要在实际环境中确认。遇到版本差异先查看对应命令的 `--help`。

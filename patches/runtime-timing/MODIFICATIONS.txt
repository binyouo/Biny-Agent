Patched Code Mode runtime modification notice

This distribution contains locally modified versions of run 2.1.6 and
@ai-sdk/code-mode 1.0.50. The modifications are not upstream published releases.
The existing ai 7.0.93 dependency is unchanged by the runtime timing patch.

run changes add an optional cumulative synchronous QuickJS execution-time budget,
exclude bridge/host waits from that budget, retain the independent wall-clock
limit, and expose executionTimeoutBudgetVersion 1 for fail-closed compatibility.
The worker is rebuilt from the patched run source with its embedded serializer
and the unchanged quickjs-wasi 3.6.0 WebAssembly artifact.

@ai-sdk/code-mode changes forward executionTimeoutMs to run, extend policy and
error-path types, and reject the option unless the underlying run runtime
advertises the exact timing contract. These changes regenerate package output
and source maps and are bundled into the application's CLI and Desktop runtime.

Original upstream copyright, license, and attribution notices are retained in
THIRD_PARTY_NOTICES.txt and patches/runtime-timing/licenses/. The complete Apache
License, Version 2.0 is in patches/runtime-timing/licenses/APACHE-2.0.txt. This
notice does not replace or alter those licenses. In built distributions, the
source-input directory is copied to dist/code-mode-runtime-provenance/.
